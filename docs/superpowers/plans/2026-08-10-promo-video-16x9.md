# Промо-ролик 16:9 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** переделать `promo/` из вертикального 40-секундного ролика в горизонтальный 1920×1080 на ровно 60.0 с, со звуком, плавным движением и одиннадцатью сценами, показывающими объём приложения через сюжет «один день».

**Architecture:** кадр держится на двух элементах — телефон-контекст 380×824 слева и «лупа» 1179×720 справа, показывающая тот же скриншот в родных пикселях DPR-3 (текст 15 px → 45 px). Данные для съёмки готовит промо-сид на локальном инстансе, наполняющий инбокс импорта через настоящий Telegram-webhook. Звук синтезируется скриптом на чистом Node.

**Tech Stack:** Remotion 4.0.507 (rspack, Tailwind v4), React 19, TypeScript 5.9, puppeteer-core 25 (системный Chrome), Node 22, ffmpeg (loudnorm).

**Спека:** `docs/superpowers/specs/2026-08-10-promo-video-16x9-design.md`

## Global Constraints

- Кадр **1920×1080**, 30 fps, композиция `Promo` — ровно **1800 кадров**.
- Темп **100 BPM**: доля 18 кадров, такт 72 кадра. Все длительности кратны 36.
- Длительности сцен: `162, 234, 162, 198, 198, 198, 162, 198, 162, 162, 144` — сумма **1980**, минус 10 переходов × 18 = **1800**.
- Абсолютные кадры старта сцен: `0, 144, 360, 504, 684, 864, 1044, 1188, 1368, 1512, 1656`.
- Источник скриншота — **1179×2556** (393×852 при DPR 3). Масштаб телефона к источнику — **0.32231**.
- Геометрия кадра неизменна во всех сценах: подпись `left 135, top 88, w 1180, h 162`; телефон `left 135, top 176, 380×824`; лупа `left 605, top 280, 1179×720`; энсо `left 1728, top 88, 56×56`.
- Палитра: фон `#09090B`, карточка `#18181B`, текст `#FAFAFA`, вторичный `#A1A1AA`, акцент `#E8C865`.
- Кегли: заголовок 72 / 700 / lineHeight 1.06 / letterSpacing −1.5; кикер 34 / 500 / lineHeight 1.25.
- Две кривые на весь ролик: вход — `Easing.bezier(0.22, 1, 0.36, 1)`, панорама и наезд — `Easing.bezier(0.65, 0, 0.35, 1)`. `Easing.linear` только у медленных дрейфов.
- Ничего не появляется быстрее 12 кадров и не въезжает быстрее 20.
- `interpolate()` пишется инлайн в `style`, значения — литералы. Свойства `scale`/`translate`/`rotate`, не `transform`. Исключение оговорено в Task 2.
- `"./src/fonts.ts"` обязан оставаться в `sideEffects` в `promo/package.json`.
- `<Audio>` импортируется из ядра `remotion`, **не** из `@remotion/media` (пакет не установлен).
- **Коммитов в плане нет.** У пользователя стоит «не коммитить без явной просьбы»; вместо шага «Commit» каждая задача заканчивается шагом проверки.
- В оверлеях **нет выдуманных чисел** — они только обводят настоящие элементы скриншота.

## Проверочный цикл

В `promo/` нет тест-раннера, и заводить его ради видео не нужно. Роль тестов играют четыре команды:

```bash
cd promo
npm run lint                                  # eslint + tsc
npx remotion compositions                     # у Promo должно быть ровно 1800
npx remotion still Promo out/f<N>.png --frame=<N> --scale=0.5
ffprobe -v error -show_entries format=duration -show_entries stream=width,height,codec_type -of default=nw=1 <file>
```

Для аудио проверка автоматическая — шаг с `ffprobe` и сравнением длительности.

**Interfaces:**

  `src` — путь внутри `public`, например `"shots/debts.png"`. `loupeTop` — вертикальное смещение в **пикселях источника** (0…1836). `children` — оверлеи, попадающие внутрь слоя лупы и потому пользующиеся координатами источника напрямую.

- [ ] **Шаг 1: написать `Stage.tsx`**

```tsx
import { Easing, Img, Interactive, interpolate, staticFile, useCurrentFrame } from "remotion";

/**
 * Кадр 16:9: телефон-контекст слева, лупа справа.
 *
 * Портретный экран целиком в широком кадре нечитаем — по высоте помещается
 * телефон ~910 px, и текст интерфейса 15 px превращается в 16 px. Поэтому
 * телефон отвечает только за «где мы», а читает зритель лупу: тот же скриншот
 * в родных пикселях DPR-3, то есть 45 px на тот же текст. Увеличения
 * интерполяцией нет вовсе — отсюда и отсутствие мыла.
 *
 * Ширина лупы равна ширине источника (1179), поэтому горизонтального
 * панорамирования не существует: лупа всегда показывает экран во всю ширину и
 * ездит только по вертикали. Одна анимируемая величина вместо двух.
 *
 * Рамка-указатель на телефоне показывает, какую полосу сейчас показывает лупа,
 * и связывает два фокуса внимания. Её координаты производные: 0.32231 — это
 * 380/1179, отношение телефона к источнику.
 *
 * Отступление от правила «в style только литералы»: `loupeTop` приходит
 * пропом, поэтому панорама не правится в Studio мышкой. Альтернатива —
 * повторить разметку лупы в девяти сценах, и тогда геометрия разъедется.
 * Геометрия важнее.
 */
export const Stage: React.FC<{ src: string; loupeTop: number; children?: React.ReactNode }> = ({ src, loupeTop, children }) => {
  const frame = useCurrentFrame();

  return (
    <Interactive.Div
      name="Stage"
      style={{ position: "absolute", left: 0, top: 0, width: 1920, height: 1080, perspective: 2600, perspectiveOrigin: "42% 52%" }}
    >
      <Interactive.Div
        name="Ambient glow"
        style={{
          position: "absolute",
          left: 40,
          top: 120,
          width: 1840,
          height: 940,
          borderRadius: 999,
          background:
            "radial-gradient(46% 52% at 34% 52%, rgba(232,200,101,0.13) 0%, rgba(232,200,101,0.04) 48%, rgba(232,200,101,0) 74%)",
          opacity: interpolate(frame, [0, 34], [0, 1], {
            extrapolateLeft: "clamp",
            extrapolateRight: "clamp",
            easing: Easing.bezier(0.22, 1, 0.36, 1),
          }),
          scale: interpolate(frame, [0, 110, 210], [0.94, 1.04, 0.99], {
            extrapolateLeft: "clamp",
            extrapolateRight: "clamp",
            easing: [Easing.bezier(0.22, 1, 0.36, 1), Easing.bezier(0.65, 0, 0.35, 1)],
            output: "perceptual-scale",
          }),
        }}
      />
      <Interactive.Div
        name="Phone"
        style={{
          position: "absolute",
          left: 135,
          top: 176,
          width: 380,
          height: 824,
          borderRadius: 24,
          overflow: "hidden",
          backgroundColor: "#09090B",
          border: "2px solid rgba(232,200,101,0.26)",
          boxShadow: "0 40px 110px rgba(0,0,0,0.55), 0 0 0 1px rgba(232,200,101,0.06)",
          opacity: interpolate(frame, [0, 20], [0, 1], {
            extrapolateLeft: "clamp",
            extrapolateRight: "clamp",
            easing: Easing.bezier(0.22, 1, 0.36, 1),
          }),
          translate: interpolate(frame, [0, 34, 210], ["0px 46px -240px", "0px 0px 0px", "0px -5px 26px"], {
            extrapolateLeft: "clamp",
            extrapolateRight: "clamp",
            easing: [Easing.bezier(0.22, 1, 0.36, 1), Easing.linear],
          }),
        }}
      >
        <Img name="Phone screenshot" src={staticFile(src)} style={{ position: "absolute", left: 0, top: 0, width: 380 }} />
        <Interactive.Div
          name="Loupe band"
          style={{
            position: "absolute",
            left: 0,
            width: 380,
            height: 232,
            top: loupeTop * 0.32231,
            borderTop: "2px solid rgba(232,200,101,0.85)",
            borderBottom: "2px solid rgba(232,200,101,0.85)",
            backgroundColor: "rgba(232,200,101,0.10)",
            opacity: interpolate(frame, [14, 34], [0, 1], {
              extrapolateLeft: "clamp",
              extrapolateRight: "clamp",
              easing: Easing.bezier(0.22, 1, 0.36, 1),
            }),
          }}
        />
      </Interactive.Div>
      <Interactive.Div
        name="Loupe"
        style={{
          position: "absolute",
          left: 605,
          top: 280,
          width: 1179,
          height: 720,
          borderRadius: 28,
          overflow: "hidden",
          backgroundColor: "#09090B",
          border: "2px solid rgba(232,200,101,0.30)",
          boxShadow: "0 50px 130px rgba(0,0,0,0.6), 0 0 0 1px rgba(232,200,101,0.07)",
          opacity: interpolate(frame, [4, 26], [0, 1], {
            extrapolateLeft: "clamp",
            extrapolateRight: "clamp",
            easing: Easing.bezier(0.22, 1, 0.36, 1),
          }),
          translate: interpolate(frame, [0, 34, 210], ["0px 30px -170px", "0px 0px 0px", "0px -9px 48px"], {
            extrapolateLeft: "clamp",
            extrapolateRight: "clamp",
```

## Task 8: Синтез звука

**Files:**

- Modify: `promo/package.json` (скрипт `audio`)
- Modify: `promo/src/Promo.tsx` (аудио-слой)

**Interfaces:**

- [ ] **Шаг 1: написать `make-audio.mjs`**

Чистый Node, без зависимостей. Структура файла:

1. **Запись WAV.** `writeWav(path, [left, right], 44100)` — 16-бит PCM, стандартная шапка RIFF/fmt/data.
2. **Примитивы.** `sine(f,t)`, `saw(f,t)` (полиблеп не нужен — сигнал уходит в фильтр), `noise()`, `expDecay(t,tau)`, `adsr(t,a,d,s,r,dur)`, `onePoleLP(state,x,a)`, `onePoleHP(state,x,a)`, `softClip(x)=Math.tanh(x)`.
3. **Голоса.** `kick` — синус с огибающей высоты 55→40 Гц и спадом 0.25 с; `hat` — белый шум через ВЧ-фильтр со спадом 0.04 с; `bass` — синус с `softClip`; `pad` — четыре расстроенные пилы (расстройка ±6 центов) через два однополюсных НЧ с атакой 0.9 с; `pluck` — треугольник со спадом 0.3 с.
