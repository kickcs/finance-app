# Дизайн: визуальный редизайн bento-плиток (цвет, глубина, композиция)

**Дата:** 2026-07-12
**Причина:** фидбек пользователя — «раньше было лучше»; плитки плоские, серые, без идентичности. Старый дашборд держал идентичность на цветных IconBadge в заголовках секций — возвращаем этот приём в плитки системно.

## Палитра: identity-цвет виджета

`WIDGET_COLORS: Record<WidgetId, string>` в `shared/config/dashboard.ts` (значения из ENTITY_COLORS-гаммы, фиксированные по смыслу домена):

| Виджет | Цвет | Хекс |
|---|---|---|
| quick_actions | янтарь | `#f59e0b` |
| accounts | синий | `#3b82f6` |
| budget | изумруд (= primary) | `#10b981` |
| top_expenses | оранжевый | `#f97316` |
| debts | фиолетовый | `#8b5cf6` |
| transactions | циан | `#06b6d4` |
| goals | роза | `#f43f5e` |
| subscriptions | индиго | `#6366f1` |

Цвет применяется ТОЛЬКО в двух местах: IconBadge шапки и цветовая дымка (см. Сигнатура). Числа/тексты НЕ красятся в цвет виджета — цвет текста остаётся за семантикой (просрочка, направление долга, прогресс бюджета).

## Глубина

- Dark: внутренняя световая кромка сверху `shadow-[inset_0_1px_0_rgb(255_255_255/0.04)]`; внешних теней нет (не читаются на почти-чёрном фоне).
- Light: мягкая `shadow-sm`.
- Существующие `bg-card-*` / `border-border-*` токены сохраняются (система не ломается).

## Сигнатура: цветовая дымка

Статичное радиальное пятно цвета виджета за шапкой: absolute-элемент ~96px, `rounded-full blur-2xl`, цвет `WIDGET_COLORS[id]` с альфой ~8% (dark) / ~10% (light), позиция за IconBadge (верхний левый угол), `pointer-events-none`. КРИТИЧНО для FPS: никакой анимации на дымке — blur растеризуется один раз. `overflow-hidden` на карточке уже есть.

## Композиция (единый ритм всех 8 плиток)

- Шапка: `IconBadge` (существующий компонент, prop `color`, компактный размер ~28px, rounded-lg) + eyebrow-лейбл: `text-[10px] font-semibold uppercase tracking-wider` вторичным цветом (перекликается с «БАЛАНС» в hero).
- Главная метрика: `text-xl font-bold tabular-nums` основным цветом текста.
- Вторичная строка: `text-xs` вторичным цветом.
- Корень плитки: `flex flex-col`; нижняя мета-строка прижимается `mt-auto` — нижние кромки плиток держат линию.
- Паддинг p-3.5 сохраняется (высота ячейки 104px).

## Что НЕ меняется

- Hero, jiggle-бейджи (✕/манипулятор), пустые состояния, скелетоны (размеры под плитку), ExpandedTileOverlay-механика (но его шапка получает тот же IconBadge с цветом для непрерывности морфа).
- Токены темы, Tailwind-классы семантики; новых зависимостей нет.

## Реализация

- `BentoTile.vue`: props `color?: string`; шапка через IconBadge + eyebrow; дымка; `flex flex-col` + slot. Скелетон-состояние сохраняется.
- Плитки: передают `:color="WIDGET_COLORS[...]"` (проще — прокинуть из TILE-слоя по id) и выравнивают внутреннюю типографику под ритм (метрика text-xl font-bold tabular-nums, вторичные text-xs).
- `ExpandedTileOverlay`: IconBadge с цветом виджета в заголовке.
- Гейты: dashboard-тесты + build.
