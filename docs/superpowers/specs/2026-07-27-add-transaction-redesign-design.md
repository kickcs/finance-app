# Редизайн экрана «Новая транзакция»

Дата: 2026-07-27
Страница: `frontend/src/pages/transactions/new/AddTransactionPage.vue` + `features/add-transaction/*`

## Бриф

Экран открывают несколько раз в день, чтобы за 3–5 секунд записать трату.
Сценарий: **сумма → категория → «Добавить»**. Всё остальное — уточнения.

## Диагноз

Экран — форма, где всё кричит одинаково громко. Сумма (единственное, что
обязательно набрать) — самый слабый элемент: «0» серым цветом, а «сўм» болтается
у правого края в 250 px от числа. Чипы счёта, три ряда категорий, две пунктирные
кнопки, ряд «Комментарий + Дата» — все с одинаковым весом и одинаковой рамкой.
Глазу не за что зацепиться.

Замеры (393×852, светлая тема): сумма получает 120 px из 852, вспомогательные
поля — 470 px, снизу 200 px мёртвого места.

Найденное агентами (3 прогона: UX / перф / a11y+анимации), что подтверждено кодом:

## Тезис

**Сумма — это экран.** Остальное — уточнение к ней.

## Токены

Палитра/шрифт — существующая система (`DESIGN_SYSTEM.md`), это редизайн одной
страницы в живом продукте, а не новый бренд. Свобода — в типографике суммы,
структуре экрана, движении.

**Цвет.** Экран НЕ перекрашивается в семантический цвет типа операции: красный
фон на «Расходе» (80% заходов) читался бы как ошибка, а трата — это норма.
Цвет тратится ровно на один глиф — знак `−`/`+` перед суммой:

| Тип | Знак | Токен |
|---|---|---|
| expense | `−` | `danger` |
| income | `+` | `success` |
| transfer / debt | нет | — |

**Типографика суммы** — сюда уходит вся смелость:

- число: `tabular-nums`, `font-semibold`, размер ступенями по числу цифр —
  ≤6 → 44 px, 7–8 → 36 px, ≥9 → 30 px (для UZS суммы длинные, 3 068 000 = 7 цифр);
- валюта: **inline**, сразу за числом, по базовой линии, 0.45× размера,
  `text-tertiary`. Число и валюта — один типографический объект, а не два
  элемента на разных концах строки;
- при мультивалютном счёте сама валюта и есть триггер поповера — отдельная
  плавающая пилюля исчезает.

вышел»; заодно освобождается 88 px и уходит странность «кнопка + подсвечена, когда
ты уже на экране добавления».

## Signature

**Строка остатка, которая считается по мере набора суммы.** Вместо статичного
«Баланс: 3 068 000» — «Останется 3 043 000» (для дохода — «Станет»). Она отвечает
на настоящий вопрос пользователя («могу себе позволить?»), а не на формальный
(«сколько было?»), и естественно перетекает в предупреждение о нехватке средств.

Вместе с ней — **чипы сумм из собственной истории**: частые суммы для выбранного
типа и категории. Для того, у кого кофе всегда 25 000, а метро 2 000, запись
превращается в два тапа. Данные уже загружены (`useRecentTransactions(userId, 50)`
для smart defaults) — новых запросов нет.

Проверка на шаблонность: типовой ИИ-ответ на «переделай форму добавления траты» —
большое число сверху плюс кастомная цифровая клавиатура плюс сетка категорий.
Клавиатуру сознательно НЕ делаем: `inputmode="decimal"` и так даёт цифровую
раскладку, а своя клавиатура ломает десктоп и поле комментария. Бюджет смелости
уходит не на неё, а на подсказки, выведенные из данных самого пользователя.

## Движение

Экран открывают десятки раз в день — входная анимация здесь чистая задержка.

- вход: было 3 группы по 500 мс с задержками 75/150 мс → стало одно затухание
  180 мс, без сдвига по Y;
- смена типа: знак `−`/`+` перекрашивается и меняется за 180 мс, подпись кнопки
  перетекает;
- первая цифра: bounce `scale(1.03)`, 160 мс (было 1.05/200);
- высота панелей: остаётся, но замер батчится через rAF;
- `prefers-reduced-motion: reduce` гасит: вход, высоту, мигание каретки,
  скользящий индикатор, `scroll-smooth`.

## Производительность

| Правка | Эффект |
|---|---|
| Окно рендера ±1 панель вокруг активной | 6 смонтированных → 3 |
| `TransferPanel`/`DebtPanel` через `defineAsyncComponent` | уходят из стартового чанка; `usePeople`/`useExchangeRates` не летят на «Расходе» |
| Замер высоты батчится в rAF, ResizeObserver только на активной панели | нет read-write thrashing на 6 узлах |
| `@scroll` через rAF | 1 замер на кадр вместо N |
| Перепарковка карусели на resize | чинит застревание между панелями |
