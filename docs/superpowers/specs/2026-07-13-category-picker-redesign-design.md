# Редизайн выбора категории в форме транзакции (mobile-first)

**Дата:** 2026-07-13
**Статус:** утверждён
**Контекст:** жалобы пользователей — тяжело выбирать категории при большом их количестве, поиск неудобен. Ревью: `.ui-design/reviews/category-picker_20260713_233919.md`.

## Проблема

`CategoryChips.vue` раскладывает категории в 4 ряда с горизонтальным скроллом (`w-max` + `overflow-x-auto`, скроллбар скрыт). При 20+ категориях сетка в разы шире экрана, категории за краем невидимы. Поиск спрятан за маленькой кнопкой, Enter не выбирает, матчинг — голый `includes`. Деление частые/редкие — ручной флажок в настройках, которым не пользуются.

## Решение (утверждённые границы)

- **Скоуп:** только форма добавления транзакции — `ExpensePanel.vue` и `IncomePanel.vue` (features/add-transaction). Остальные 7 мест использования `CategoryChips` не трогаем, сам `CategoryChips.vue` не меняется.
- **Частые категории:** автоматически по последним транзакциям; fallback на ручной `isFrequent`, когда транзакций < 5. Страница настроек категорий не меняется.
- **Создание категории из пикера:** не входит; вместо этого кнопка «Управление категориями» (переход на существующую страницу настроек) в пустом результате поиска и внизу шита.
- **Архитектура:** вариант A — новые компоненты рядом с `CategoryChips`, без режимов внутри него.

## Компоненты

### `entities/category/ui/CategoryPicker.vue` (инлайн)

Пропсы: `categories: Category[]`, `selectedId: string`, `label?: string`, `transactions?: Transaction[]`. Эмит: `select: [categoryId: string]`. Если `transactions` не передан или пуст — работает fallback-ветка по `isFrequent` (см. useFrequentCategories). `CategoryPickerSheet` рендерится внутри `CategoryPicker` (локальный стейт `sheetOpen`) — потребителю виден один компонент.

- До **8** частых чипов в `flex-wrap` (обычно 2 ряда, без горизонтального скролла) + чип **«Все категории · N»** (иконка сетки), открывающий шит. N — общее число категорий.
- Выбранная категория, не попавшая в топ-8 (выбор из шита, quick-action preset), **пинится первым чипом**. Если выбранная категория отсутствует в `categories` (удалена) — пин не рендерится.
- Если категорий всего ≤ 9 — показываем все, чип «Все категории» скрыт.
- Стиль чипов как в `CategoryChips` (иконка + название; у выбранного — цвет категории в тексте/рамке/фоне), но **без sliding indicator** — чипы статичны, достаточно `transition-colors`. Нет `rows`, «Ещё N», инлайн-поиска.
- A11y: контейнер `role="radiogroup"` + `aria-label` из `label`; чипы `role="radio"` + `aria-checked`.
- Haptics: `trigger('selection')` при выборе.

### `entities/category/ui/CategoryPickerSheet.vue` (шит)

Пропсы: `open: boolean`, `categories: Category[]`, `selectedId: string`. Эмиты: `update:open`, `select`.

- `vaul-vue` `DrawerRoot`, как в `SplitExpenseDrawer`: `direction` = `bottom` на мобиле / `right` на desktop (`useIsDesktop`).
- Структура: handle (только мобила) → заголовок «Категория» + кнопка закрытия → **поле поиска (sticky)** → скроллируемая сетка → кнопка «Управление категориями» внизу.
- Autofocus поиска **только на desktop**; на мобиле фокус по тапу (клавиатура не съедает шит при открытии).
- Сетка: **4 колонки**, плитка = `IconBadge` (иконка в цветном кружке) + название снизу, тап-таргет ≥ 44pt. Выбранная плитка подсвечена цветом категории. Порядок — **как в БД** (пользователь управляет им через reorder в настройках).
- Выбор: тап → haptic `trigger('selection')` → эмит `select` → шит закрывается.
- Пустой результат поиска: «Ничего не найдено» + кнопка «Управление категориями».
- «Управление категориями» ведёт на страницу настроек категорий (существующий роут); шит закрывается.

### `entities/category/model/useFrequentCategories.ts` (частотность)

Чистая функция/composable: `(categories, transactions, topN = 8) → Category[]`.

1. Считает употребления `category_id` по переданным транзакциям (окно — последние 20, тот же кэш `useRecentTransactions(userId, 20)`, что питает `useSmartDefaults`; **ноль новых запросов**). Учитываются только id, присутствующие в `categories` (тип панели уже отфильтрован снаружи).
2. Если транзакций **< 5** — возвращает fallback: категории с `isFrequent !== false` в порядке БД (текущее поведение), обрезанные до `topN`.
3. Если по статистике частых меньше `topN` — добор: сначала `isFrequent`-категории, затем остальные в порядке БД.

Тип `Transaction` импортируется из `shared/api/database.types` (как в `useSmartDefaults`) — границы FSD соблюдены, кросс-импорта entity→entity нет.

### Поиск (внутри шита)

- Нормализация запроса и названий: lowercase, trim, схлопывание пробелов, `ё → е`.
- Ранжирование: совпадение по **началу слова** выше, чем `includes` в середине.
- `enterkeyhint="done"`; Enter выбирает первое совпадение; первое совпадение визуально подсвечено.
- Логика — чистые функции в `entities/category/model/categorySearch.ts`, чтобы покрыть юнит-тестами.

## Интеграция

- `ExpensePanel.vue`, `IncomePanel.vue`: `CategoryChips` → `CategoryPicker`; новый проп `transactions` пробрасывается из `TransactionForm.vue` (там уже есть `useRecentTransactions(userId, 20)`).
- Экспорт новых компонентов из `entities/category/index.ts`.
- Пропсы `searchable`/`rows` в этих двух местах уходят вместе с `CategoryChips`.

## Краевые случаи

| Случай | Поведение |
|---|---|
| Новый пользователь, 0–4 транзакции | fallback на `isFrequent` (как сейчас) |
| Выбранная категория не в топ-8 | пин первым чипом |
| Выбранная категория удалена | пин не рендерится, «— выберите» в лейбле |
| Категорий ≤ 9 | все инлайн, без чипа «Все категории» |
| Смена типа расход/доход при открытом шите | шит закрывается (смена панели размонтирует его) |
| Enter при пустом результате | ничего не делает |

## Тесты

- **Юнит `useFrequentCategories`**: ранжирование по частоте; fallback при < 5 транзакций; добор до topN (isFrequent → порядок БД); игнор category_id, отсутствующих в списке. Образец — `useSmartDefaults.spec.ts`.
- **Юнит поиска**: нормализация (ё/е, регистр, пробелы); приоритет prefix-совпадений; пустой запрос.
- **Компонентный `CategoryPicker.spec.ts`**: рендер топ-8 + «Все категории · N»; пин выбранной вне топа; скрытие кнопки при ≤ 9 категорий; эмит `select`. Образец — `CategoryChips.spec.ts`.
