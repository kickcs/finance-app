# Компактный редизайн страницы настроек (Профиль)

Дата: 2026-07-26
Страница: `frontend/src/pages/profile/ProfilePage.vue` (роут `/profile` — он же экран настроек)

## Проблема

Замер на iPhone 14 Pro (390×844, светлая тема, демо-аккаунт):

| Метрика | До |
|---|---|
| Высота контента `<main>` | **1913 px** |
| Экранов прокрутки | **2.62** |

Причины:

1. **Одна настройка = одна строка во всю ширину** (`py-3.5` + чеврон). 12 таких строк подряд — это ~650 px на элементы, каждый из которых несёт 1–2 слова.
2. **Шесть секционных заголовков** (`Настройки`, `Оформление`, `Уведомления`, `Telegram-импорт`, `Данные`, `Приложение`), каждый со своим `mb-2` и внешним `space-y-6`. Только на «хром» секций уходит ~230 px.
3. **Секции-одиночки**: «Оформление» — один тумблер, «Данные» — один пункт. Заголовок весит столько же, сколько содержимое.
4. **Блок push-уведомлений (≈380 px) всегда развёрнут**, даже когда push выключен — тогда он показан на `opacity-50 pointer-events-none`. Это самый большой блок страницы, и в самом частом состоянии он полностью неинтерактивен.
5. **Дублирующие подписи**: «Предстоящие списания» + «Напомним за несколько дней до списания подписки». Второе не добавляет ничего к первому.

## Дизайн-направление

Страница перестаёт быть списком дверей и становится **панелью состояния**: видно не «куда можно пойти», а «как сейчас настроено».

Ключевая структурная мысль — сейчас страница смешивает четыре разных типа элементов в одну визуальную форму (строка + чеврон). Форма должна кодировать тип:

| Тип | Что это | Форма |
|---|---|---|
| **Значение** | валюта, язык, начало месяца, цвет | плитка: подпись + текущее значение |
| **Раздел** | категории, люди, быстрые действия, импорт | плитка: подпись без значения |
| **Переключатель** | Liquid Glass, push и его типы | полоса во всю ширину (бинарное состояние требует широкого трека) |
| **Подключение** | Telegram, подписка | карточка со своим акцентом |

### Токены

Собственной палитры страница не заводит — она живёт внутри дизайн-системы Ouro:

| Роль | Токен |
|---|---|
| Плитка | `bg-card-*` + `border-border-*`, `rounded-xl` |
| Подложка | `bg-background-*` |
| Подпись плитки | `text-body-sm` (13 px) / `font-medium` / `text-text-primary-*` |
| Значение | `text-caption` (11 px) / `text-text-tertiary-*` |
| Заголовок секции | `text-caption` / `font-semibold` / `uppercase` / `tracking-wider` / `text-text-tertiary-*` |
| Чип иконки | 24×24, `rounded-lg`, `bg-surface-*`, иконка `size="xs"` |

Заголовки секций уходят в верхний регистр 11 px: они становятся тише самих плиток, но остаются якорями при беглом просмотре — раньше 12 px semibold спорил по весу с содержимым.

### Сигнатурный элемент

**Чип плитки «Основной цвет» залит живым `primary`** — единственная плитка на странице, которая показывает своё значение пигментом, а не текстом. Всё остальное монохромно, поэтому этот один квадрат читается как «вот твой цвет» без подписи. Заодно это снимает проблему: у цветов в `PRIMARY_COLORS` нет русских названий, и подпись пришлось бы выдумывать.

Это же и принятый риск: сетка вместо канонического списка настроек и отказ от чевронов на плитках. Чеврон в плитке 160 px — шум; нажимаемость несёт сама карточка (press-состояние + ring фокуса).

## Результат

Замер тем же способом (390×844, демо-аккаунт, светлая тема):

| Метрика | До | Цель | Стало |
|---|---|---|---|
| Высота `<main>` | 1913 px | ≤ 1000 px | **947 px** (−50 %) |
| Экранов прокрутки | 2.62 | ≤ 1.4 | **1.30** |

На десктопе (≥640 px) страница целиком помещается без прокрутки.

## Порог качества

- Каждая плитка — настоящий `<button>` с видимым focus-ring и целью нажатия ≥ 44 px.
- Раскрытие деталей push уважает `prefers-reduced-motion`.
- Светлая и тёмная темы — только токены, ни одного сырого цвета Tailwind.
- Тексты: подпись подписывает, значение показывает. Ни одна строка не делает двойную работу.
