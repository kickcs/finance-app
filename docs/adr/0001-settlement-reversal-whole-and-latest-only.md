# Расчёт отменяется только целиком и только последний

Записи одного действия по долгу (платёж с отработкой, переплатой и прощением, зачёт, «Закрыть все») связаны общим `transactions.settlement_id` и снимаются только вместе: удаление любой из них из истории, отмена закрытия и удаление долга отменяют весь расчёт. Отменить можно только последний расчёт каждого затронутого долга, иначе 409 «Сначала отмените более поздний расчёт…». Частичная отмена и отмена «из середины» отвергнуты: остаток долга и балансы счетов пришлось бы пересчитывать по всей цепочке более поздних расчётов, а отмена зачёта или «Закрыть все» по одному долгу оставила бы встречный долг погашенным без пары.

## Consequences

- Отмена закрытия одного долга после «Закрыть все» или зачёта открывает все долги этого расчёта и возвращает всю сумму; интерфейс об этом предупреждает.
- Связку старых записей проставила миграция `BackfillTransactionSettlement` по прежнему правилу (одна дата у записей платежа). Её `down` ничего не делает: `up` трогает только пустые `settlement_id`, а колонку снимает `down` схемы. Вернуть старую группировку по дате нельзя.
- Каждый расчёт и его отмена блокируют строки затронутых долгов `FOR UPDATE` в порядке `id`, до блокировки записей.
